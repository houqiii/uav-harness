# 网页控制台

在已拉取的项目目录运行。先退出占用同一串口的终端控制台或地面站连接，等待任务收尾。

```bash
git pull --ff-only
bash scripts/mac-dashboard.sh
```

打开 <http://127.0.0.1:8080>。脚本复用终端入口的 Python 查找、虚拟环境和锁定依赖安装流程，不需要 Node/npm。无硬件的 VLM 闭环使用 `--offline`；旧飞控协议测试使用 `--mock`。

## VLM 在线任务

页面标题为“无人机群意图控制系统”，默认打开“VLM 在线任务”。同一个 Qwen VLM 读取自然语言、图像、遥测和上一轮执行结果，在线决定下一步观察、转向、接近、高度调整或悬停。浏览器固定流程、预设视觉检测和动画进度已移除。

```bash
export DASHSCOPE_API_KEY='自己的百炼官方密钥'
bash scripts/mac-dashboard.sh --offline
```

不接串口也能采集几何仿真图像，点击“启动闭环”后真实请求 Qwen。缺少密钥或账户不可用会显示错误，不会伪造决策。主界面右上显示遥测，右下显示当前观测图像、目标框及拍摄姿态；可以查看每轮决策和执行结果。相机/飞控端口已独立，实机按配置接入。

完整架构、运行方式、相机标定、策略边界、暂停/人工接管恢复和当前验证限制见 [VLM 在线闭环](vlm-brain.md)。本次实际 Qwen 请求返回 `Arrearage`，账户恢复后才能验证真实多轮模型效果。

原有自然语言编译、台架控制、视频和遥测保留在“指令工作台”（`/#console`）。下述 DeepSeek 配置与编译流程均指该兼容工作台。

多串口用 `--port /dev/cu.usbserial-XXXX`，只观察用 `--observe`，HTTP 端口用 `--http-port 8081`。已有机群配置可用 `bash scripts/mac-dashboard.sh --config examples/mock-fleet.json`；该方式保留配置中的机型、链路、控制开关、状态目录和 HTTP 绑定。默认实机入口与已验收终端使用相同的 ArduCopter 4.5 / board 1010 / sys 1 / comp 1 模型机配置，且共用 `state/bench-console` 的任务记录与未决结果约束。

## 不接串口：离线测试 LLM 调度

```bash
export DEEPSEEK_API_KEY='自己的密钥'
bash scripts/mac-dashboard.sh --offline
```

打开 <http://127.0.0.1:8080>。默认命令 `bash scripts/mac-dashboard.sh` 未检测到 USB 串口时也会自动进入此模式；`--offline` 可保证即使电脑上有串口也不打开。多串口歧义或显式指定串口出错时仍会报错，不悄悄切换模式。

离线表示不连接飞控。模型请求固定使用 DeepSeek 官方 `https://api.deepseek.com` 和 `DEEPSEEK_API_KEY`；不读取 USTC 密钥，不接受 `DEEPSEEK_BASE_URL` 的第三方地址覆盖，也不会失败后切换服务商。界面显示官方地址。需要有效的 DeepSeek 官方密钥及模型服务网络。此模式不启动协议模拟器，不产生遥测，不发送 MAVLink 命令；服务端拒绝动作、计划执行及 `execute:true`，网页执行按钮也停用。它不读取或更改实机 SQLite 任务记录。

默认提供 3 份虚拟能力档案：`ap-1`（ArduPilot 可飞行）、`px4-1`（PX4 可飞行）、`model-1`（模型机，只开放台架动作）。展开“推演机群与能力”查看与模型提示词相同的动作列表、最大高度和最大相对距离。已有硬件档案可用 `--offline --config examples/model-serial.json` 加载能力，仍不连接其中配置的设备。

可点击“前后移动”“异构协同”“越界请求”填入例句，再点击“生成调度计划”。例如：

> ap-1 起飞2米，向机头前进3米，再后退1米，悬停2秒后降落

查看动作列表与默认展开的 JSON：前后移动应使用 `body_flu`，前进 x 为正、后退 x 为负；检查 action_id / depends_on 是否正确串联。异构示例可检查两架飞机并行执行和共同到达后的依赖。越界示例用于检查能力/范围拒绝，而不是自动修正成另一个任务。生成计划只证明类型、能力、参数和 DAG 校验通过；无法代替用户对原句含义的判断，也不证明真实飞机当前满足执行条件。

`--mock` 是另一种模式：会运行 MAVLink 软件协议对端，允许测试任务执行/回执/收尾。离线推演只检查 LLM 输出，二者不要混淆。没有密钥时界面仍可打开、填入例句和查看能力，但不会伪造模型输出。关闭服务后不保留离线预览。

## 一句话调度

在启动服务的同一终端配置已有 DeepSeek 密钥；密钥只在后端使用，不要填进网页或提交到 Git。

```bash
export DEEPSEEK_API_KEY='自己的密钥'
bash scripts/mac-dashboard.sh
```

1. 输入“让模型机 model-1 的 1 号电机以 1231 微秒测试 5 秒”，点击“生成调度计划”。模型只翻译，预览阶段不派发控制。
2. 查看动作、目标飞机、参数、依赖或展开 JSON；点击“执行计划”提交同一份计划。修改原文后必须重新生成。
3. 在执行记录中查看 TX、定向 ACK、动作结果；右上 PWM、姿态、模式、armed、落地状态随真实遥测更新。ACK 接受与任务完成分开呈现。

未配置 DeepSeek 时，“单电机测试”“起飞探针”可生成明确标注的固定测试计划。它们只在所选 model_bench 机型下开放，不能当作自然语言翻译结果。没有定位的模型机不会开放前后移动，起飞探针只证明指令/输出和收尾。

任务提交响应丢失时，页面保留原幂等键；点击“查询 / 重试本次提交”不会重复派发已经接收的任务。待确认提交在本浏览器会话内保存，刷新后可恢复；服务中的近期任务从 SQLite 加载。取消任务会继续等待原收尾逻辑，结果不确定时明确显示 UNKNOWN，不自动重放。可点“核实地面状态”调用既有 reconcile 接口；它只核实新鲜地面/未解锁状态，不把原任务改为成功，丢失 ACK 后仍需重启服务才能复用相应命令。

右上飞机选择器仅切换监测对象和快捷示例的目标。自然语言可指定机群中的其他飞机；以生成计划里展示的 vehicle_id 为准。

## 模型与生成进度

默认使用 DeepSeek 官方 `deepseek-v4-pro`，开启推理、强度为 `low`。启动前可设置 `DEEPSEEK_MODEL` 和 `DEEPSEEK_REASONING_EFFORT=low/high/max/none`；none 才关闭推理。界面显示实际模型，不会隐藏回退或自动切换。已显式配置其他模型时仍尊重该配置。

计划预览通过 `/v1/intents/preview-stream` 接收进度，区分“等待模型输出”“模型正在推理”“正在生成调度计划”，持续显示耗时；心跳不等于生成结果。可点击“停止生成”，修改原文也会关闭上游请求。服务器连接时限 5 秒、读取空闲时限 30 秒、总时限 180 秒；上游心跳不能延长总时限。浏览器等待上限为 200 秒，不再在 55 秒直接中止一个仍活跃的生成。

只有收到完整结束状态、JSON 解析以及 Harness 校验均通过后才展示计划；截断或异常断流不接受半份结果。模型内部推理文本不保存、不展示。旧 `/v1/intents` 接口仍可使用，生成期间不会发送飞控指令。

2026-10-15 排查时，同一官方密钥、同一网络下，Flash 的最小请求 150 秒内只返回心跳，Pro 则约 0.8 秒开始正文；这只描述本次观测，不表示 Flash 一直不可用。Pro 实际调度计划编译用时约 21 秒，网页完整生成约 23.2 秒。若你之前设置过 `DEEPSEEK_MODEL=deepseek-flash`，可改为 `deepseek-v4-pro` 后重启。

## 云台画面与姿态

“连接设置”中为当前飞机填写 HTTP(S) 视频地址并选择格式：

- MJPEG：直接通过浏览器图像元素显示。
- 原生视频：浏览器支持的 MP4；Safari 可直接播放 HLS。其他格式需要视频网关提供浏览器可播放的输出。

RTSP 不能直接放入网页播放，需要将设备 RTSP 先转为 MJPEG、可播放的 HTTP 视频等地址。本项目不内置转码网关。视频配置仅保存在当前浏览器，服务端不代理任意地址；未接入、流错误和服务离线均明确显示。

姿态被动接收同一 MAVLink 系统上各组件广播的 `GIMBAL_DEVICE_ATTITUDE_STATUS`，提供俯仰、横滚、航向、航向参考系、组件/设备 ID、故障标志及消息时效；多个云台可切换。`VIDEO_STREAM_INFORMATION` 用于显示设备宣告的视频元信息，消息存在不代表画面已连通。未收到姿态就显示“未接入”，即便视频可播也不虚构角度。载荷接收与飞控身份/定向 ACK 匹配相互独立。协议依据：[Gimbal v2](https://mavlink.io/en/services/gimbal_v2.html)、[Camera v2](https://mavlink.io/en/services/camera.html)。

云台必须通过现有链路广播/路由这些消息；本入口不自动配置设备输出频率，不提供新增云台控制动作。真实云台与视频尚待设备现场验收。

## 鉴权与退出

服务设置 `HARNESS_API_TOKEN` 时，在网页“连接设置”的 API 访问令牌里填写相同值。静态界面可加载，所有数据和控制 API 仍要求 Bearer。令牌保留在当前浏览器会话中，不出现在 URL。

关闭标签页不会取消已提交任务。停止服务用终端 Ctrl+C，等待已有任务收尾。HTTP 服务保持单进程、默认本机绑定。
