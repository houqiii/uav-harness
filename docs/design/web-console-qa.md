## 功能

- `pytest -q`：51 项通过，1 项现有 Starlette/httpx 弃用警告。
- 新增测试覆盖静态页面和 API 鉴权分离、模型配置状态、PWM、独立云台组件、过期/无效四元数、持久化任务恢复、不重放、预览/校验不发送动作、执行展示的同一份计划且不重新调用模型、提交幂等。
- Playwright：固定计划→单电机任务→PWM 1231→TX/ACK→输出归位/未解锁→成功；刷新恢复任务。
- Playwright：模拟模型上游 HTTP 响应，输入一句话→DeepSeekCompiler→计划预览→提交同一 Plan→真实 MAVLink 编解码协议对端完成；修改原文后旧计划失效。
- Playwright：提交已接收但 HTTP 响应丢失，近期任务查询恢复结果；只有一个任务且仅一次 command 209。取消运行任务后等待停止/未解锁，再经网页核实地面状态；不把原任务改判成功。
- Playwright：独立组件发送云台姿态，显示 -30°；消息过期后角度清除；测试 HTTP MJPEG 640×360 连续图像显示；无效视频地址显示错误，服务断开清空遥测并禁用执行。
- 两个 Mac 启动脚本均验证；Bash、JavaScript、Python 语法检查通过。
- wheel 构建通过；将 wheel 解压到隔离目录实际导入并启动，确认 HTML 与全部 7 个静态资源都能提供，不依赖源码目录或 Node。

## 边界

此次没有连接实机或真实云台。外部 DeepSeek 实际请求出现 ReadTimeout，页面正确呈现失败；模拟上游闭环通过不能代替外部服务验收。真实视频流与硬件云台广播/路由还需现场接入。原有飞控验收范围保持文档中的区分，见 [验证边界](../verification.md)。

## 离线推演补充

完整测试更新为 56 项。沿用既有设计系统，新增模式标签、能力档案折叠区和三条例句；浏览器 1536×1024 / 390×844 检查通过，view_image 检查离线界面及多动作 JSON 状态。截图：[离线推演](web-console-offline.png)。默认不接 USB 即可启动，也可强制 --offline；不打开串口/UDP 链路或协议模拟器，实机日志完全隔离。测试用模型上游返回“解锁→起飞→前进→后退→悬停→降落”，验证 UI 显示坐标、依赖、JSON 且没有任务执行；模型拒绝不支持/越界请求时清除旧计划。另验证原硬件待确认提交不会锁住离线输入，也不会被离线测试抹除。真实上游最小请求读取超时，离线硬件独立不代表模型网络离线。
