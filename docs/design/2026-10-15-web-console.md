# 网页控制台

采用与 Python API 同源的原生 HTML/CSS/ES Modules，随 Python wheel 打包；另一台 Mac 无需 Node 或前端构建。布局遵循 web-console-concept.png：顶部服务状态与设置，左侧意图/计划/任务，右上遥测，右下视频/云台姿态。深蓝黑背景 #0b1016、面板 #111923、边框 #26313f、强调色 #43d6b0；12px 圆角、系统中文字体与等宽数字。小屏按工作台、遥测、云台顺序纵向排列。

意图预览调用既有 /v1/intents execute=false，执行时直接提交已展示的 Plan 到 /v1/plans，不再次编译。每次提交具有固定幂等键；网络不确定时复用原键，避免重复动作。更改原文使预览失效；后台任务有独立状态、原始 JSON、TX/ACK 与结果。取消复用原收尾逻辑。刷新后从持久化任务恢复展示。

/v1/dashboard 每秒提供飞机、编译器配置状态、近期任务和载荷快照；每条数据保留既有时效规则，页面连接失败立即停止展示旧数据为在线。不自动触发控制。真实服务复用用户已验收的模型机 settings；mock 显著标识协议模拟，仍运行真实调度与 MAVLink 编解码。DeepSeek 未配置时可使用明确标注的固定测试计划，不能冒充模型翻译。

载荷监听与飞控 ACK/身份监听分开，接收已配置飞机同系统的云台/摄像机组件，不放宽控制 ACK 匹配。读取 GIMBAL_DEVICE_ATTITUDE_STATUS 与 VIDEO_STREAM_INFORMATION；四元数归一化、角度与航向参考系、故障与过期明确显示。没有设备显示未接入，不制造数值。视频设置支持 HTTP(S) MJPEG、浏览器原生视频；RTSP 显示需要转为浏览器可播地址，不假装播放。视频地址按当前飞机保存在浏览器，不由服务器代理任意 URL。

静态页面无需 Bearer，可在连接设置输入 API token；数据接口保持原鉴权，密钥不下发。新增 Mac 启动脚本复用原依赖安装过程，默认本机绑定，支持 --mock / --observe / --port / --config，实机状态目录与控制台共享以保留未决任务约束。

验证：后端 API、预览无控制、已展示计划派发、独立组件载荷来源与时效、鉴权、wheel 静态资源；浏览器验证自然语言预览（模拟上游）、固定测试/执行/取消、视频错误、离线与桌面/移动布局。外部 DeepSeek 与真实云台/视频需设备现场验收。
