## 验收记录

后端 69 项 Python 测试通过；新增测试覆盖官方 DeepSeek 地址、流式语义解析、预设来源、飞行限高不变、零飞行任务、拒绝无关输出、拒绝执行与空输入。4 项 Node 状态测试覆盖 12 个独立方位、完成悬停、暂停冻结、重置、未找到、丢失／超时悬停和重复启动拒绝。Node 只用于开发验证。

使用 Codex 内置浏览器验证，未使用 Playwright Chromium 备用浏览器。通过浏览器自带的 Playwright 定位器及可访问性控件执行操作；部分自定义视口下的点击定位失败后改用同一浏览器的可访问性按钮操作，操作成功。

- 官方 DeepSeek 真实解析：浏览器返回完整语义任务约 4.0 秒；后续阶段仍明确标注预设视觉与模拟遥测。
- 正常流程：12/12 方向、120° 候选、水平 20.0 m、高度 50.0 m、速度 0.0 m/s，最终“已到达观察位置”。
- 暂停／继续：扫描暂停时演练时间及采集状态保持，继续后完成；重置清空结果。
- 历史帧：选择 0° 后显示“扫描帧 01”、对应采集时间、000° 航向，隐藏目标框；不沿用当前 120° 的目标画面。
- 未找到：扫描完毕后悬停，距离保持未知。
- 目标丢失／视觉超时：均在水平 60 m 处停止，速度为零，显示原因；丢失场景不继续显示目标框。
- 原指令工作台：切换后演练自动暂停，真实模式／位置仍为“—”，没有模拟数据泄漏或飞行任务。
- 自由输入：修改为其他目标时固定模板启动按钮禁用，需要真实模型解析；不会静默运行红帽子模板。
- 响应式：1536×1024 桌面、390×844 手机及内置浏览器常规尺寸检查。手机主标题保持可见，方位盘与候选信息纵向排列，12 帧分 3 行，没有横向溢出，13 个图片元素全部加载。
- Wheel 构建通过，已确认 demo Python 模块、JS/CSS 与 JPEG 素材均包含于安装包。
